## ✨ Features

- ⚡ **Blazing Fast** with Vite for near-instantaneous HMR
- 🎨 **Beautiful UI** with shadcn/ui and Radix UI components
- 🔒 **Type Safety** with TypeScript throughout the stack
- 🎯 **Modern React** with React 19 features and best practices
- 🛠️ **Developer Experience** with ESLint, Prettier, and more
- 📱 **Fully Responsive** designs that work on all devices
- 🔄 **Seamless SPA** experience with Inertia.js

## 🚀 Quick Start

1. **Clone the repository**

    ```bash
    git clone https://github.com/yourusername/laravel-react-starter.git
    cd laravel-react-starter
    ```

2. **Install dependencies**

    ```bash
    composer install
    npm install
    ```

3. **Setup environment**

    ```bash
    cp .env.example .env
    php artisan key:generate
    ```

4. **Start the development server**

    ```bash
    # Start Laravel backend
    php artisan serve

    # In a new terminal, start Vite dev server
    npm run dev
    ```

5. Open [http://localhost:8000](http://localhost:8000) in your browser.
